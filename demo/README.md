# FCO · Kick Off & Arena 交互 Demo v2

零依赖 · 单 HTML 文件 · 双击即运行 · 离线可用。基于视觉稿 PNG 底图 + 透明热区，加入基础交互逻辑、状态管理、微动效。适合 5 分钟内部评审走流程。

## 使用

**双击 `demo/index.html`**，浏览器里自动等比缩放到视窗。

## 主流程（推荐演示路径）

```
① 选球队
  · 点任一球队卡 → 高亮选中 + toast「已选择球队」
  · 点底部「选择」 → 未选球队时 warn；已选 → 跳到 ②
  ↓
② 选球员
  · 点池子里的球员卡 → 高亮，累计计数
  · 第 12 个点击 → warn「首发已满 11 人」
  · 11 人齐 → toast 提示可开始
  · 点底部「开始冠军之路」 → 不足 11 人 warn；够了 → 跳 ③
  ↓
③ 养成室 · 阵容 Tab（核心枢纽）
  · 二级 Tab：阵容 ↔ 任务 ↔ 排行榜（立即切换，无刷新）
  · 「所有球队」→ ⑩ 全屏弹窗
  · 一级导航：商店 / 兑换商城 / 球队养成
  · 隐藏彩蛋：右上角「待领取」区域点击 → ⑧ 五星达成弹窗
  ↓
④ 任务 Tab
  · 点「一键领取」→ 积分 +999，+999 绿色飘字上升，toast 提示，1 秒后 → ⑨ 养成成功弹窗
  · 单条「领取」→ +100 / +200 / +50 飘字反馈
  ↓
⑤ 排行榜 Tab → ⑥/⑦ 商店/兑换
  · 商店卡片点击 → toast「已购买」
  · 售罄卡点击 → warn「已售罄」
```

## 已实现的交互

| # | 功能 | 反馈 |
|---|---|---|
| ✅ | 页面切换 | 280ms 淡入淡出 |
| ✅ | 球队卡选中 | 绿色高亮描边 + 辉光 |
| ✅ | 球员卡多选（上限 11） | 高亮切换，超限 warn |
| ✅ | 按钮校验（未选/未满）| warn toast 阻止跳转 |
| ✅ | Tab 切换 | 立即响应 + devbar 联动高亮 |
| ✅ | 弹窗 | fade 背景 + scale(0.92→1) 弹入 |
| ✅ | Toast 提示 | 底部上浮，2.2s 自动消失，3 种语义色 |
| ✅ | 积分飘字 | +N 绿色从点击位置上浮 1.1s |
| ✅ | 购买/兑换/售罄区分反馈 | 不同 toast 文案 |
| ✅ | 重置按钮 | 恢复初始状态 |
| ✅ | 调试热区可视化 | 按 H 键切换绿色虚线边框 |
| ✅ | 键盘快捷键 | ← → 切屏 / Esc 关弹窗 |

## 评审演示脚本（3 分钟版）

1. 打开 Demo（10s）— 介绍这是活动的视觉还原 + 主流程走查
2. **走选队流程**（30s）— 演示"先选一个→再点选择 CTA 生效"的校验逻辑
3. **走选人流程**（40s）— 点 11 个球员演示多选+计数，说一下超过 11 个的处理
4. **养成室主站**（60s）— 三个 Tab 来回切，讲阵容可视化+段位统计的意图
5. **任务领取**（30s）— 点"一键领取"演示积分动画 + 养成成功弹窗
6. **商店/兑换**（30s）— 强调"用同一套卡片骨架 + 区分币种"
7. **答疑**（剩余时间）

## 后续改造建议（按优先级）

- 🔴 **真拖拽**：选球员页目前是"点击切换"，真拖拽需要切分图层 + HTML5 Drag API，工作量一天
- 🟡 **切 Tab 动画更细**：当前是直接切屏，可以改成横向滑动（需要把 3 个 Tab 做成一个 wrapper 里的 flex 子元素）
- 🟡 **球队卡真数据**：30 支球队真实 logo + 名称（需要你导出或我用 API 扒）
- 🟢 **背景音乐 / 按钮音效**：给 .mp3 放进 `assets/sfx/`

## 修改热区位置

按 `H` 显示绿色虚线边框，直接在 index.html 搜对应的 `.hot` 改 `style="left: X%; top: Y%; width: W%; height: H%;"`
