01 / BACKGROUND

项目背景

FCO 活动是一款基于足球俱乐部养成的 H5 互动活动，玩家通过选择心仪球队、组建专属阵容、完成成长任务、查看排行榜并在商店与兑换商城获取奖励，逐步达成赛季养成目标。

05 / COMPONENTS

组件沉淀

可复用的卡牌组件 / Tab 组件 / 动效系统

01

球员卡

足球游戏核心展示组件，根据当前段位 Tab 控制亮起数量。

已选 · 彩色未选 · 黑白压暗
02

任务卡

任务列表行卡 1457×135，配合 4 种按钮态控制不同流程。

默认Hover已领取领取增益去完成
03

Tab 切换组

双 Tab · 段位 Tab · 球队 Tab（带横滑翻页动画）三种范式统一。

默认Hover选中翻页滑动
04

入场动效系统

统一 fx-in / fx-zoom / fx-slide 三种入场 + data-fx-delay 错峰控制。

FadeUpZoomSlideRight切屏重启
05

渐隐滚动视口

球员卡 / 商品卡共用：mask 渐变 + 隐藏滚动条 + 平滑滑动。

底部 110px 渐隐绿色滚动条
06

积分胶囊 / 弹窗体系
